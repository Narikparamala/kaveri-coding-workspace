Kaveri Coding Privacy Policy

Last updated: 24 August 2026

Information we use

Kaveri Coding uses Google Sign-In to receive basic account identity information such as your name and email address. The platform also stores information needed for academic coding activities, including batch membership, coding submissions, visible test results, marks, review status, timestamps, and teacher feedback.

How we use information

This information is used to authenticate users, deliver coding assignments, record submissions, manage academic batches, and allow faculty to review student work and provide feedback.

Google user data

Kaveri Coding uses Google authentication for identity only. It does not request access to Gmail, Google Drive, Google Calendar, contacts, or other unrelated Google services.

Service providers

The platform uses Supabase for authentication and application data services and Vercel for web hosting.

Contact

For privacy questions or account-data requests, contact narikparamala@gmail.com.
