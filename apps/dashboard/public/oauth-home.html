Kaveri Coding

Kaveri Coding is an academic coding-assignment platform operated by Kaveri Technologies Academy. Students sign in with Google to access coding assignments in VS Code, join their assigned batch, run visible tests, submit solutions, and view teacher feedback. Faculty use the web dashboard to create questions, manage batches, and review submissions.

Google Sign-In is used only to identify the student or faculty account. Kaveri Coding does not request access to Gmail, Google Drive, Google Calendar, or other unrelated Google services.
